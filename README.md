# GYM LOG

Обновлённая версия дневника тренировок (версия 2.5.0). Проект не требует сборщика и сторонних JavaScript-библиотек: интерфейс работает как набор обычных ES-модулей.

## Запуск

1. Распакуйте архив.
2. Откройте папку `gym-log` в терминале.
3. Запустите локальный сервер:

   ```bash
   python -m http.server 8080
   ```

4. Откройте `http://localhost:8080` в браузере.

ES-модули обычно не запускаются напрямую через `file://`, поэтому для модульной версии используйте локальный сервер. Для быстрого запуска без сервера в корне проекта приложен файл `gym-log-standalone.html` — это собранная одностраничная версия.

Чтобы пересобрать standalone-файл после изменения модулей или CSS, установите dev-зависимость сборщика и выполните:

```bash
npm install
npm run build:standalone
```

TypeScript используется только при сборке единого HTML-файла; для обычного запуска модульного приложения в браузере он не нужен.

## Анализ исходной версии и изменения

**Сохранено:** тренировочная программа, отметки выполненных упражнений, история занятий, расписание, секундомер, таймер и светлая/тёмная темы. Существующие ключи истории и активной тренировки в `localStorage` оставлены, поэтому уже записанные в этом браузере занятия должны сохраниться.

**Убрано или исправлено:** убрана ссылка на отсутствующую функцию `openVidModal()`, которая вызывалась из расписания; удалено повторяющееся отображение времени активной тренировки, которое не обновлялось.

**Добавлено:**

- Добавлен экран профиля и единственная кнопка быстрого перехода в правой части верхней панели. Профиль не дублируется в нижней навигации.
- Добавлены поля веса, роста, возраста и необязательной цели по весу.
- ИМТ пересчитывается при вводе. Числовое значение видно сразу; категория и математическая разница до границы диапазона появляются после указания возраста и только для взрослых 18+. Это не диагноз и не предписание худеть; для лиц младше 18 лет нужна отдельная возрастная оценка.
- Добавлен отдельный журнал личных рекордов во вкладке «Прогресс»: упражнение/тренажёр, вес, повторения, дата и комментарий. Записи можно добавлять, изменять и удалять; лучший результат по каждому упражнению помечается. В профиле раздела достижений больше нет.
- Интерфейс стал адаптивным: широкая область контента для компьютеров, карточная сетка расписания и адаптация профиля для мобильных экранов.
- Добавлен самостоятельный экран «Прогресс» в нижнюю навигацию вместо прежней кнопки «Профиль». Профиль открывается только кнопкой в правом верхнем углу.
- Добавлен спокойный абстрактный фон: мягкие зелёные свечения, тонкая сетка и геометрические дуги. Кнопки получили градиенты, деликатные тени и короткие состояния наведения; светлая тема адаптирована.
- Каталог расширен дополнительными популярными базовыми упражнениями. Дополнительные позиции не добавляются в расписание автоматически и не меняют заданный план.
- Во время активной тренировки можно раскрыть «Журнал подходов» прямо в карточке упражнения каталога и записать подход в текущую сессию. Это не отмечает упражнение из программы выполненным и не изменяет состав плана.

## Хранение данных

Все данные хранятся локально в `localStorage` браузера. Backend, аккаунта и синхронизации между устройствами нет.

| Ключ | Назначение |
|---|---|
| `gym_history` | Завершённые тренировки (старый ключ сохранён) |
| `gym_session` | Активная тренировка (старый ключ сохранён) |
| `gym_theme` | Тема оформления (старый ключ сохранён) |
| `gym_profile_v1` | Параметры профиля и текущий вес |
| `gym_achievements_v1` | Личные рекорды (отображаются во вкладке «Прогресс»; старый ключ сохранён) |
| `gym_sets_v1` | Журнал подходов |
| `gym_body_weight_history_v1` | История измерений массы тела |

Не очищайте данные сайта, иначе локальные записи будут удалены. На другом устройстве эти данные автоматически не появятся.

## Обновление: журнал подходов, прогресс и каталог

### Журнал подходов

- В активной тренировке у каждой карточки упражнения есть раскрываемый блок «Журнал подходов».
- Для каждого подхода записываются вес в килограммах, количество повторений и один показатель усилия: RPE или RIR.
- RPE принимает значения от 1 до 10; RIR — от 0 до 10. В форме выбирается один из двух способов оценки.
- Показываются подходы текущей сессии и последний подход из предыдущих сессий для этого же `exerciseId`.
- Подход можно удалить. Номер следующего подхода рассчитывается по максимальному уже сохранённому номеру в данной сессии.
- Записи привязаны к `sessionId`, упражнению и дате. Перезагрузка страницы не теряет их.
- При подтверждённой отмене тренировки удаляются подходы этой незавершённой сессии. При завершении тренировки подходы остаются в журнале.
- Отдельная запись подхода сама по себе не отмечает упражнение выполненным: эти два действия независимы.

### Графики динамики

- В профиле появился раздел «Динамика прогресса» с двумя графиками, отрисованными встроенным SVG без внешних библиотек.
- График веса тела строится из датированных измерений. При повторном вводе за ту же дату значение заменяется, а не дублируется.
- При сохранении изменённого веса профиля создаётся измерение на текущую дату. На существующих установках с заполненным профилем, но пустой историей, текущее значение добавляется как первая точка графика.
- Из блока измерений можно указать вес и дату вручную. Запись за текущую дату обновляет текущий вес профиля и ИМТ; запись за прошедшую дату влияет только на график и не перезаписывает сегодняшний показатель.
- Для графика рабочих весов выбирается упражнение с записанными подходами. На каждую дату берётся самый тяжёлый фактически записанный подход.
- График показывает именно использованный вес, а не расчётный одноповторный максимум (1ПМ). Значения для разных тренажёров могут быть несопоставимы между собой.

### Каталог упражнений

- Добавлена вкладка «Каталог» в нижнюю навигацию.
- Каталог собирает упражнения из текущей недельной программы и убирает повторные совпадения по названию.
- Есть поиск по названию, мышцам и оборудованию, а также фильтрация по группам: грудь, спина, плечи, руки, ноги/ягодицы, кор и кардио.
- В карточках есть целевые и вспомогательные мышцы, оборудование, заметка из программы и внешние материалы.
- Для части базовых движений добавлены прямые страницы с техникой и видеодемонстрацией. Для упражнений, для которых отдельная проверенная страница не была подобрана, открывается общий видео-справочник Muscle & Strength; видеокнопка открывает поиск YouTube по точному названию упражнения. Это именно поиск видео, не гарантия конкретного ролика.
- Внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.

### Регрессионная совместимость и ограничения

- Сохранены существующие ключи `gym_history`, `gym_session` и `gym_theme`; новый журнал использует отдельные ключи.
- Для ранее сохранённой активной тренировки без `sessionId` идентификатор создаётся на основе времени её начала.
- Старые сессии не содержат записей подходов задним числом — журнал начинает собирать фактические значения только после обновления.
- Для подходов пока нет редактирования; запись можно добавить или удалить.
- Данные пока не синхронизируются через интернет и не имеют серверной резервной копии.

### Установка favicon на хостинге

Загрузите каталог `assets/`, `site.webmanifest` и `index.html` в одну папку на сайте. Пути уже относительные (`./assets/...`), поэтому приложение можно размещать не только в корне домена, но и в подпапке. После публикации обновите страницу с очисткой кеша или проверьте сайт в приватном окне: браузеры могут кешировать favicon отдельно от HTML.

## Обновление 2.5.0 — редактируемое расписание и история тренировок

- Удалена отдельная вкладка «История» из нижней навигации. История завершённых тренировок и статистика перенесены на экран «Расписание» — под карточками всех тренировочных дней.
- После сохранения завершённой тренировки приложение открывает «Расписание», где сразу видна обновлённая история.
- Экран расписания стал редактируемым: для каждого дня недели можно добавлять пользовательские упражнения, менять название, схему подходов/повторов, основные и дополнительные мышцы, а также заметку о технике.
- Упражнения можно удалять из конкретного дня. Перед удалением показывается подтверждение.
- Пользовательский план сохраняется в localStorage под ключом `gym_workout_plan_v1` и загружается до первой отрисовки экрана «Сегодня».
- Экран «Сегодня» использует тот же объект плана, поэтому изменения расписания автоматически отображаются в программе на соответствующий день и в новой тренировочной сессии.
- При изменении плана во время активной сессии список отметок выполненных упражнений приводится в соответствие с оставшимися упражнениями.
- Ввод пользовательских названий, мышц, схем подходов и заметок экранируется перед выводом в HTML.
- Старые записи `gym_history`, `gym_session`, подходы и достижения не затрагиваются.
- Нижняя навигация теперь содержит «Сегодня», «Расписание», «Каталог», «Таймер» и «Прогресс». Профиль по-прежнему доступен только кнопкой в правой части верхней панели.
- Модальная форма редактора расписания адаптируется к мобильной ширине.

### Проверка обновления 2.5.0

- Проверены связи навигации: отдельный `view-history` и `nav-history` удалены; контейнер истории расположен непосредственно в `view-schedule`.

- После изменения плана в активной сессии очищаются только отметки упражнений, которых больше нет в соответствующем дне. Записи подходов не удаляются.
- Пустой день разрешён: проценты выполнения и статистика корректно обрабатывают тренировку без упражнений, не деля на ноль.
- Обработчики добавления и редактирования проверяют обязательные поля; пользовательский текст экранируется при формировании HTML.
- Для пересборки автономного HTML после изменений выполните `npm run build:standalone`.
