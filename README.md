# GYM LOG

Обновлённая версия дневника тренировок. Проект не требует сборщика и сторонних JavaScript-библиотек: интерфейс работает как набор обычных ES-модулей.

## Запуск

1. Распакуйте архив.
2. Откройте папку `gym-log` в терминале.
3. Запустите локальный сервер:

   ```bash
   python -m http.server 8080
   ```

4. Откройте `http://localhost:8080` в браузере.

ES-модули обычно не запускаются напрямую через `file://`, поэтому используйте локальный сервер. Для быстрого запуска без сервера в корне архива приложен файл `gym-log-standalone.html` — его можно открыть двойным щелчком.

## Анализ исходной версии и изменения

**Сохранено:** тренировочная программа, отметки выполненных упражнений, история занятий, расписание, секундомер, таймер и светлая/тёмная темы. Существующие ключи истории и активной тренировки в `localStorage` оставлены, поэтому уже записанные в этом браузере занятия должны сохраниться.

**Убрано или исправлено:** убрана ссылка на отсутствующую функцию `openVidModal()`, которая вызывалась из расписания; удалено повторяющееся отображение времени активной тренировки, которое не обновлялось.

**Добавлено:**

- Добавлен экран профиля и отдельная кнопка быстрого перехода в верхней панели.
- Добавлены поля веса, роста, возраста и необязательной цели по весу.
- ИМТ пересчитывается при вводе. Числовое значение видно сразу; категория и математическая разница до границы диапазона появляются после указания возраста и только для взрослых 18+. Это не диагноз и не предписание худеть; для лиц младше 18 лет нужна отдельная возрастная оценка.
- Добавлен раздел достижений: упражнение/тренажёр, вес, повторения, дата и комментарий. Записи можно добавлять, изменять и удалять; лучший результат по каждому упражнению помечается.
- Интерфейс стал адаптивным: широкая область контента для компьютеров, карточная сетка расписания и адаптация профиля для мобильных экранов.

    ├── app.js           # Точка входа и переключение экранов
    ├── core/

    │   └── metrics.js   # Расчёт ИМТ и весовых ориентиров

    │   └── workouts.js  # Данные тренировочной программы

## Хранение данных

Профиль, достижения, история, текущая тренировка и тема сохраняются в `localStorage` браузера. Backend, аккаунта и синхронизации между устройствами в этой версии нет. Не очищайте данные сайта, если хотите сохранить записи.

## Что логично добавить следующим этапом

- Журнал подходов для каждого упражнения: вес, повторы и RPE/RIR.
- Графики динамики веса тела и рабочих весов.
- Резервное копирование и восстановление данных в JSON/CSV.
- Каталог упражнений с корректными ссылками на технику и видео.
- Серверную авторизацию и синхронизацию между устройствами, когда появится backend.
